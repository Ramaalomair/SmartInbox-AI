# Order, Return and Refund Policy (POL-CS-01)
Order status must be checked via lookup_order before making delivery-status claims. Do not promise a delivery date unless the order record explicitly contains a confirmed date. Customers may request a standard return within 14 calendar days of delivery, subject to condition review. A refund is not confirmed unless refund_status = completed in the authoritative order record. A pending refund is not proof that money was received. Request order ID if absent, rather than guessing. Escalate an order complaint to HIGH if the message alleges financial harm, repeated unsuccessful contact, or imminent time-sensitive consequences; otherwise MEDIUM for active order/refund complaints and LOW for general product queries.

For synthetic examples, the standard 14-day return window is measured from confirmed delivery date to the fixed fixture reference date 2026-10-28. Within-window status does not guarantee eligibility or approval. Refund processing completion is determined strictly by refund_status=completed; no universal processing-time promise is documented, so do not invent a timeline. Missing confirmed dates must not be inferred.
